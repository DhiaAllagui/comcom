# comcom

**COMCOM Group (Creative Solutions)** — Modern corporate website for an international creative solutions holding based in the United Arab Emirates (Dubai), accredited by the UAE Free Zone.

## Divisions & Ecosystem
- **COMCOM Studios**: Audiovisual production, corporate films, documentaries, 2D/3D visual effects & television broadcast.
- **COMCOM Events & Expo**: Large-scale world expos, international pavilions, corporate summits & VIP galas.
- **COMCOM Advertising & Media**: Multichannel global campaigns, brand architecture & AR activations.
- **COMCOM Enterprise**: Custom leadership training, business/leisure tourism & global trading.
- **Proprietary Labels**: CIA (Central Influencers Agency), Influencers International Academy, Start Up Academy, IMS, ITS.
- **Digital Publishing**: *Influencers Mag*, *Start Up Mag*, *Mag Santé*, *Destinations Mag*.

## Tech Stack
- React 18
- Vite
- Tailwind CSS
- Lucide React
